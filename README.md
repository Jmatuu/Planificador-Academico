# Planificador Académico

Aplicación web diseñada para ayudar a los estudiantes a organizar sus actividades académicas, administrar sus pendientes y planificar mejor su tiempo de estudio.

## Descripción

El **Planificador Académico** busca facilitar la organización estudiantil mediante un espacio donde se puedan registrar asignaturas, tareas y exámenes. La aplicación permitirá visualizar las actividades pendientes, ordenarlas según su fecha y prioridad, y distribuir el tiempo disponible para estudiar.

## Objetivos

- Registrar asignaturas, tareas y exámenes.
- Organizar actividades según fechas y prioridades.
- Identificar las actividades pendientes y completadas.
- Visualizar el progreso académico.
- Generar un plan de estudio sencillo según el tiempo disponible.

## Funcionalidades principales

- **Gestión de asignaturas:** registrar y organizar materias.
- **Gestión de actividades:** agregar tareas y exámenes con fechas y prioridades.
- **Organización:** visualizar las actividades en orden de importancia y fecha.
- **Seguimiento:** marcar actividades como completadas.
- **Progreso:** consultar el estado de las actividades.
- **Planificación:** distribuir actividades según las horas disponibles para estudiar.

## Plataforma

El proyecto está orientado principalmente a la web, con un diseño adaptable a diferentes tamaños de pantalla.

## Almacenamiento

La primera versión utilizará almacenamiento local en el navegador. No requiere cuentas de usuario ni conexión a un servidor.

> Los datos se almacenan en el navegador del dispositivo. Si se eliminan sus datos de navegación, la información guardada podría perderse.

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/Jmatuu/Planificador-Academico.git
```

### 2. Entrar al proyecto

```bash
cd Planificador-Academico
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar la aplicación en web

```bash
npm run web
```
